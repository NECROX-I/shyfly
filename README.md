# Shyfly 🦋 — For Every Woman, Every You

Full-stack e-commerce for a women's store: **Ornaments · Clothing · Footwear · Handbags · Eyewear · Accessories** — each with its own sub-categories, mega-menu entry, shop page and home-page shelf.

**Stack:** MongoDB · Express · React 18 (Vite) · Tailwind · Framer Motion · Zustand · Razorpay · Cloudinary · Resend (same family as your Loknath codebase).
